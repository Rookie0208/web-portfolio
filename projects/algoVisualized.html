01 / Overview

Turn abstract logic into something you can see.

Algo Visualizer is a web project built to make sorting algorithms easier to understand through visual representation. Instead of only reading code or looking at a final sorted array, learners can watch how values move and change during the process.

The project explores a more visual approach to learning programming fundamentals, helping students connect the logic of an algorithm with its behaviour.
