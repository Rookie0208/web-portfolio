HRMS

A web application for managing everyday HR operations.

Web application HR operations Internship project

01 / Overview

A closer look at the project.

The Human Resource Management System (HRMS) was developed to make routine employee and HR activities easier to manage through a single web application. Instead of keeping information and day-to-day tasks scattered across different places, the platform brings the core HR experience into one organised interface.

I worked on the project during my Software Developer Internship at Optimum Info, contributing across the application — from building the user interface to implementing server-side functionality and connecting the application with its database. The project gave me practical experience in taking a web application from an initial requirement to a working product.

The focus was to keep the experience straightforward: make information easy to access, keep common HR tasks organised, and provide a consistent place for users to work with employee information.
